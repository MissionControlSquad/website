### Site Speed Optimization Checklist

- [ ] Core Web Vitals compliance (<2.5s LCP, <100ms FID, <0.1 CLS)
- [ ] Image optimization (WebP format, lazy loading)
- [ ] Minify CSS/JS (30%+ file size reduction)

### Schema Markup Implementation

- Organization schema for brand recognition
- Product schema for platform features
- FAQ schema for content pages
- Article schema for blog content

## Content Optimization Framework

### On-Page SEO Template

**Title Tag Formula**: Primary keyword + benefit + brand (50-60 chars)
**Meta Description Formula**: Problem + solution + CTA (150-160 chars)
**Header Structure**: H1 (primary), H2s (secondary), H3s (long-tail)
**Internal Linking**: 3-5 internal links per 1000 words

### Content Optimization Checklist

For each article:

- [ ] Primary keyword in title, URL, H1, first paragraph
- [ ] Secondary keywords in H2s and throughout content
- [ ] Long-tail keywords in H3s and body
- [ ] Featured snippet optimization (lists, tables, Q&A)
- [ ] Image alt text with relevant keywords
- [ ] 3-5 internal links per 1000 words
- [ ] 2-3 external links to authoritative sources
- [ ] Clear, compelling call-to-action
