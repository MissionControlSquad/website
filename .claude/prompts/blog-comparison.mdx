### Step 3 — Write the Post

Follow **Type A — Comparison Post** structure from `.claude/commands/blog.md` exactly:

- Hook (acknowledge competitor is genuinely useful, then pivot to the real question)
- What [Competitor] does well (bullet list, be fair)
- The core limitation for teams managing AI agents
- Comparison table (8+ rows, always include pricing)
- Workflow comparison (step-by-step, their way vs AgentCenter way)
- "Can you use both?" section — answer honestly
- Bottom line (2–3 sentences max)
- CTA (see `.claude/commands/blog.md` for comparison CTA format)

**Word count:** 1000–1600 words. Do not exceed 1600.

Include at least one Mermaid diagram showing the workflow difference. Use `<br/>` for line breaks inside labels — never `\n`.

**Tags:** Use proven tag patterns from `blog.md`. Always include `comparison` and `ai-agents`. Max 5 tags total.

**Date field:** Use **yesterday's date** in IST (current date minus 1 day) with the fixed Type A slot `T00:00:00+05:30`. Format: `YYYY-MM-DDTHH:MM:00+05:30`. Example: if today is 2026-05-01, use `"2026-04-30T00:00:00+05:30"`. Never use today's date or a future date. Verify it is not already used by another post.

**Filename:** `content/blog/agentcenter-vs-[competitor-slug].mdx`
Run the SEO checklist from `blog.md` before saving.

---

### Step 4 — Branch, Commit & PR

1. Write the MDX file to `content/blog/[slug].mdx`
2. Update `public/llms.txt` — append to the end of the `## Blog` section (before `## Legal`):
   `- [Post Title](https://agentcenter.cloud/blogs/[slug]): One-line description of what the post covers.`
   Also increment the post count in the Blog Index line (e.g. `39 posts` → `40 posts`).
3. `git checkout -b blog/vs-[competitor-slug]`
4. `git add content/blog/[slug].mdx public/llms.txt`
5. `git commit -m "blog: add comparison post — AgentCenter vs [competitor]"`
6. `git push origin blog/vs-[competitor-slug]`
7. Open a PR from `blog/vs-[competitor-slug]` → `main` with title: `blog: AgentCenter vs [competitor]`
8. **Do NOT merge the PR.** Leave it open for the site owner to review and merge.
