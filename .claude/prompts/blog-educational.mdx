### Step 3 — Write the Post

Follow **Type B — Educational / How-To Post** structure from `.claude/commands/blog.md` exactly:

- Direct opening (state the problem, no fluff)
- The concept explained plainly
- Step-by-step numbered sections
- Real example using a specific AgentCenter feature or workflow
- Common mistakes or misconceptions
- Bottom line
- CTA (see `.claude/commands/blog.md` for educational CTA format)

Include at least one Mermaid diagram illustrating the process or workflow described.

**Date field:** This task is scheduled at `02:00 IST on Wednesday`. Calculate what calendar date that falls on and use it as the post date in `YYYY-MM-DD` format. Anchor to the scheduled slot — not execution time.
**Include in tags:** `best-practices` or `how-to` as one of the tags
**Filename:** `content/blog/[how-to-slug].mdx`

### Step 4 — Branch, Commit & PR

1. Write the file to `content/blog/[slug].mdx`

6. Open a PR from `blog/edu-[slug]` → `main` with title: `blog: [topic]`
7. **Do NOT merge the PR.** Leave it open for the site owner to review and merge.
