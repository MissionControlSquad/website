### Step 3 — Write the Post

Follow **Type C — Use-Case / Industry Post** structure from `.claude/commands/blog.md` exactly:

- Hook (name the role/industry, name the real daily problem they hit managing agents)
- The specific bottleneck (2–3 concrete examples of what breaks without a control plane, specific to this role)
- Feature-to-workflow mapping (which AgentCenter features solve their problems — be concrete, name the feature, show the example)
- The numbers (typical agent count for this role, which plan fits, what it replaces)
- Before vs After table (Without AgentCenter | With AgentCenter — rows: visibility, task handoffs, error detection, cost tracking, debugging time)
- Where to start (one recommended first feature to set up)
- CTA (see `.claude/commands/blog.md` for use-case CTA format)

Include at least one Mermaid diagram showing how this team's agents flow through AgentCenter.

**Date field:** This task is scheduled at `02:00 IST on Friday`. Calculate what calendar date that falls on and use it as the post date in `YYYY-MM-DD` format. Anchor to the scheduled slot — not execution time.
**Include in tags:** the role/industry name and `ai-agents` as tags
**Filename:** `content/blog/ai-agents-for-[role-or-industry-slug].mdx` or `content/blog/[role-slug]-ai-agent-management.mdx`

---

### Step 4 — Branch, Commit & PR

1. Write the file to `content/blog/[slug].mdx`
2. `git checkout -b blog/usecase-[slug]`
3. `git add content/blog/[slug].mdx`
4. `git commit -m "blog: add use-case post — AI agents for [role/industry]"`
5. `git push origin blog/usecase-[slug]`
6. Open a PR from `blog/usecase-[slug]` → `main` with title: `blog: AI agents for [role/industry]`
7. **Do NOT merge the PR.** Leave it open for the site owner to review and merge.
