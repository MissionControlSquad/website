---

### Step 3 — Write the Post

Follow **Type D — Perspective / Lessons Learned Post** structure from `.claude/commands/blog.md` exactly:

- Scene-setting opener (specific, grounded — real numbers, real situation, not generic)
- The shift or realization
- Concrete examples (specific failure modes, specific features, real numbers where possible)
- What the reader should take away (a decision, a habit, a frame — not a product pitch)
- Who this matters most for (role + specific situation)
- Honest caveat — don't oversell AgentCenter or AI agents generally
- CTA (see `.claude/commands/blog.md` for perspective CTA format)

Include at least one Mermaid diagram illustrating the failure mode, pattern, or concept being discussed.

**Date field:** This task is scheduled at `02:00 IST on Sunday`. Calculate what calendar date that falls on and use it as the post date in `YYYY-MM-DD` format. Anchor to the scheduled slot — not execution time.
**Include in tags:** `production` or `best-practices` or `observability` as one of the tags
**Filename:** `content/blog/[topic-slug].mdx`

---

### Step 4 — Branch, Commit & PR

1. Write the file to `content/blog/[slug].mdx`
2. `git checkout -b blog/perspective-[slug]`
3. `git add content/blog/[slug].mdx`
4. `git commit -m "blog: add perspective post — [topic]"`
5. `git push origin blog/perspective-[slug]`
6. Open a PR from `blog/perspective-[slug]` → `main` with title: `blog: [topic]`
7. **Do NOT merge the PR.** Leave it open for the site owner to review and merge.
